# Working preferences

- After every change to this app, run the appropriate checks, commit the change, and push it to `origin/main`. Do not leave completed changes only in the local workspace.
- The user has given standing authorization for these routine commits and pushes; do not ask for confirmation each time.
- After pushing, verify that the Vercel production deployment succeeds before reporting the change as live. If the push or deployment fails, report the blocker clearly.
